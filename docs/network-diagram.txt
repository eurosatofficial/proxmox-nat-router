Outbound:
  10.0.0.0/24 → vmbr1 → MASQUERADE → vmbr0 → Internet

Inbound port forward:
  Internet → vmbr0:external-port → DNAT → guest:destination-port

Hairpin port forward:
  guest → public IPv4:external-port → DNAT + MASQUERADE → guest

Scope:
  - dedicated two-bridge IPv4 topology
  - all guests connected to vmbr1
  - IPv6 is not configured by this project
